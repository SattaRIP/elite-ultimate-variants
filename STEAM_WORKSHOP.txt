=== STEAM WORKSHOP DESCRIPTION ===

[h1]Elite Variants[/h1]

Adds powerful elite and ultimate variant creatures with fully customizable difficulty settings.

[h2]Features[/h2]

[b]Elite and Ultimate Variants[/b]
[list]
[*] [b]Elite Variants[/b]: Enhanced creatures with white/silver visual theme
[*] [b]Ultimate Variants[/b]: Golden supreme variants with significantly higher power
[*] Both spawn naturally based on player level and zone tier
[/list]

[b]Mixed Enhancement System[/b]
Each variant receives a random mix of:
[list]
[*] Physical Mutations (33 types)
[*] Mental Mutations (27 psychic powers)
[*] Cybernetics (Tier 4-8 implants)
[*] Equipment (Tier 6-8 weapons and armor)
[/list]

[b]Elite Army Encounters[/b]
[list]
[*] Small Squad: 2-3 elites
[*] Elite Patrol: 4-5 elites
[*] Elite Warband: 1 ultimate + 4-5 goons
[*] Ultimate Host: 2 ultimates + 6-8 goons
[*] Titan Pair: 2-3 ultimates
[/list]

[b]Full Customization[/b]
Configure everything via mod options:
[list]
[*] 4 Difficulty Presets: Normal, Hard, Brutal, Nightmare
[*] Custom mode with 25+ individual settings
[*] Power, HP, and Enhancement multipliers
[*] Spawn rates and chances
[*] Mutation caps and equipment settings
[/list]

[h2]Difficulty Presets[/h2]

[table]
[tr][th]Preset[/th][th]Elite Power/HP[/th][th]Ultimate Power/HP[/th][/tr]
[tr][td]Normal[/td][td]1.0x / 1.5x[/td][td]1.5x / 2.0x[/td][/tr]
[tr][td]Hard[/td][td]2.0x / 2.5x[/td][td]3.0x / 4.0x[/td][/tr]
[tr][td]Brutal[/td][td]2.5x / 3.5x[/td][td]4.0x / 6.0x[/td][/tr]
[tr][td]Nightmare[/td][td]3.0x / 5.0x[/td][td]6.0x / 10.0x[/td][/tr]
[/table]

[h2]Wish Commands[/h2]

[list]
[*] [b]spawnelite[/b] - Spawn an elite variant
[*] [b]spawnultimate[/b] - Spawn an ultimate variant
[*] [b]spawnarmy[/b] - Spawn an elite army
[*] [b]elitepreset[/b] - Apply a difficulty preset
[*] [b]elitecleanup[/b] - Remove all elite creatures
[/list]

[h2]Compatibility[/h2]

[list]
[*] Compatible with vanilla Caves of Qud
[*] Compatible with creature mods (variants can be any creature)
[*] Safe to add or remove mid-save
[/list]

[h2]Configuration[/h2]

Go to: Options > Mods: Elite Variants

All settings are available in the mod options menu with helpful descriptions.

[b]To apply a difficulty preset[/b]: Use the [b]elitepreset[/b] wish command in-game.

=== UPLOAD INSTRUCTIONS ===

1. Open Caves of Qud
2. Go to: Options > Mod Configuration
3. Find "Elite Variants" in the list
4. Click "Upload to Steam Workshop"
5. Fill in the title and description (copy from above)
6. Select visibility (Public recommended)
7. Add preview image (optional but recommended)
8. Click Upload

Alternatively, use the CoQ mod tools command line:
  - Navigate to the mod folder
  - Run the Steam upload tool provided by Freehold Games

=== GITHUB RELEASE INSTRUCTIONS ===

1. Create a new GitHub repository named "EliteVariants-CoQ" or similar
2. Initialize with the contents of the EliteVariants folder
3. Create a release with tag "v1.0.0"
4. Zip the entire EliteVariants folder as the release asset
5. Include README.md and CHANGELOG.md as release notes

Files to include in release:
  - manifest.json
  - ModOptions.xml
  - ObjectBlueprints.xml
  - PopulationTables.xml
  - Factions.xml
  - Scripts/EliteVariants/*.cs (all C# files)
  - README.md
  - CHANGELOG.md

Files to EXCLUDE from release:
  - ModOptions.xml.backup
  - ModOptions.xml.disabled
  - STEAM_WORKSHOP.txt (internal use only)
  - COMMANDS.txt (development notes)
  - SETTINGS.md (development notes)
  - WISH_COMMANDS.md (development notes)
  - NATURAL_SPAWNING.md (development notes)
